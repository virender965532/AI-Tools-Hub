StockCraft AI

CrewAI-powered Industry Stock Picker — reproducible, auditable shortlist generation

🚀 Overview

StockCraft AI orchestrates specialized agents to translate an industry brief into a ranked shortlist of investable companies. It enforces deterministic steps, caches intermediate artifacts under outputs/, and supports configurable preferences like value/growth/balanced weighting.

🧠 AI Architecture & Workflow

The system uses CrewAI to assemble a crew of focused agents, each with clear roles and YAML-driven prompts. The pipeline runs sequentially so each artifact is auditable and reusable.

  • Industry Mapper — creates precise search vocabulary.
  • Company Discovery — enumerates candidates from primary sources.
  • Fundamental Screener — collects normalized financials and applies filters.
  • Valuation Analyst — computes rank-based scores.
  • News & Risk Analyst — scans headlines for material events.
  • Shortlist Writer — synthesizes the final picks and Markdown brief.

🤖 AI Reasoning Pipeline

  1. User supplies parameters (industry, region, n_picks, min_mcap, valuation_pref).
  2. Industry Mapper returns keywords and pitfalls (YAML).
  3. Company Discovery returns 20–40 candidate briefs (JSON).
  4. Fundamental Screener gathers metrics and filters by market cap.
  5. Valuation Analyst ranks candidates by configurable weights.
  6. News & Risk Analyst adds recent headlines and sentiment.
  7. Shortlist Writer outputs JSON picks and a Markdown brief (outputs/06_shortlist.md).

🧩 Design Patterns

Factory & Strategy

Create agents and swap reasoning strategies via YAML.

Chain of Responsibility

Sequential, auditable pipeline with strict artifact handoff.

Observer / Trace

Logs and caches help with reproducibility and debugging.

Command & Facade

Modular tasks and a single entry point to run the pipeline.

🎯 Core Functionalities

  1. Configurable pipeline (value/growth/balanced).
  2. YAML-driven agent prompts and auditable outputs.
  3. Search + scrape + code-execution toolset for reliable data gathering.
  4. Shortlist JSON + Markdown brief with timestamped provenance.

🧬 Advanced Concepts

  • Rank-based scoring with deterministic NA handling and tie-breakers.
  • Short-term and long-term memory for context reuse.
  • Tool-enabled data lineage: clear source URLs and timestamps.
